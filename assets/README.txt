Drop your real files into this folder with these EXACT names:

  video1.mp4          <- plays first
  video2.mp4          <- plays automatically right after video1 ends
  photo.jpg           <- the picture on the final letter screen

Optional (nice to have, shown before each video loads):
  video1-poster.jpg
  video2-poster.jpg

Tips:
- Keep videos reasonably small/compressed (a phone-recorded clip trimmed to
  under ~30-60 seconds, exported at 720p, is usually well under 20MB and
  loads fast on mobile data). Large files will feel slow on her phone.
- photo.jpg works best as a roughly square image (it's shown in a circle).
- If a file is missing, the site shows a friendly placeholder instead of
  breaking, so you can test everything else before the media is ready.
